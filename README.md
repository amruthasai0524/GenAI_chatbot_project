# GenAI Chatbot Project 🤖✨

## 📖 Overview
This project focuses on building a Generative AI-powered Chatbot capable of understanding and responding to user queries intelligently using Natural Language Processing (NLP) and Large Language Model (LLM) concepts. ## 🚀 How to Run the Project

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/amruthasai0524/GenAI_chatbot_project.git
```

### 2️⃣ Open Project Directory

```bash
cd GenAI_chatbot_project
```

### 3️⃣ Install Required Libraries

```bash
pip install pandas numpy streamlit langchain openai google-generativeai
```

### 4️⃣ Run the Application

```bash
streamlit run app.py
```

OR

```bash
python app.py
```
